
## 按钮库
### 内联按钮的语法

必须包含以 button 开头的 ButtonID，后面使用短横分割

```CSharp
`button-[your id]`
```

### 临时缓存新增笔记按钮

在「临时缓存」文件夹下以「当前时间」为标题，以 [[「Page」Cache]] 为模板的临时笔记。作用是创建一个新的笔记，并切换到编辑模式。

```button
name 新建缓存
type note(缓存/<% tp.date.now("YYYY年MM月DD日 HH时mm分ss秒") %>) template
action 「Page」Cache
color orange
templater true
```
^button-temp

### 创建一个新的主题文件夹

在当前目录下创建新主题，主题指的是一个文件夹，内部包含同名 markdown 文件作为主题主页。

1. 弹出对话框让用户输入主题名称。
2. 在当前目录下创建主题文件夹，在主题文件夹下创建同名的主题主页。
3. 主题主页使用 [[「Page」TopicHome]] 模板。
4. 自动打开主页。

```button
name 创建新主题
type append template
action 「Page」NewTopic
templater true
color purple
```
^button-topic

必须保留 [[「Page」NewTopic]] 和 [[「Page」TopicHome]] 模板，这是为了可以使用斜杠命令创建主题和主页。

### 在主题页面下创建新笔记

在当前目录下创建新笔记，并且执行 [[「Page」NewFile]] 模板中的代码。

 1. 弹出对话框让用户输入新笔记标题
 2. 在当前目录下创建空白笔记文件
 3. 自动打开新笔记并切换到编辑模式

```button
name 创建新笔记
type command
action Templater: Insert 「Page」NewFile
color blue
```
^button-note

### 添加今日标题

点击按钮后会在下方增加当天的日期的二级标题。

```button
name 添加今日内容
type append text 
action ## <% tp.date.now("YYYY-MM-DD") %> 
templater true
```
^button-today

### 创建当日笔记（时光）

在「时光」对应分类文件夹中创建当天的 `YYYY年MM月DD日.md`，已存在则直接打开。文件会写入 `日期` 属性，供日历统计。

四个按钮位于 [[时光]] 页面，逻辑在 [[TimeNote.js]]，模板为 [[「Page」New初见]]、[[「Page」New往日]]、[[「Page」New案头]]、[[「Page」New拾语]]。

### 打开剪藏

点击按钮会打开 「附件/Todo/剪藏.md」

```button
name 打开剪藏
type link
action obsidian://open?vault=笔记&file=附件/Todo/剪藏.md
color green
```
^button-clipper
