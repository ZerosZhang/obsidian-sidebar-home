# Obsidian 侧边栏主页插件 — 需求文档

> 版本：v2.2.0 | 更新：2026-07-21

## 1. 概述

开发一个 Obsidian 侧边栏视图插件（View 类型），在左侧边栏中与文件列表并排显示，承担"主页"功能。提供快速创建笔记/日记、收藏夹快捷导航、待处理状态概览，以及 Edge-TTS 神经网络语音朗读的能力。

---

## 2. 功能需求

### 2.1 插件基础信息

| 项目 | 说明 |
|------|------|
| 插件名称 | 侧边栏主页 / Sidebar Home |
| 插件 ID | `sidebar-home` |
| 显示位置 | 左侧边栏，与文件列表同级 |
| 插件类型 | ItemView 视图类插件 |
| 视图图标 | `home` |
| 视图标题 | 主页 |
| 最低 Obsidian 版本 | 0.15.0 |
| 平台支持 | 桌面端全平台（`isDesktopOnly: true`，因 Edge-TTS 依赖 Node.js `tls`） |

---

### 2.2 模块一：快速创建按钮

侧边栏最上方提供两个并排按钮。

#### 2.2.1 新建笔记

| 项目 | 要求 |
|------|------|
| 按钮文案 | `📝 新建笔记` |
| 按钮颜色 | 绿色（`hsl(145, 63%, 42%)`） |
| 目标文件夹 | 设置项 `cacheFolder`，默认 `缓存` |
| 文件命名 | `yyyy年MM月dd日 HH时mm分ss秒`（如 `2026年05月22日 09时15分30秒`） |
| 打开方式 | 新标签页，编辑模式（`mode: 'source'`） |
| 文件内容 | 空白文件 |

**边界：** 文件夹不存在则自动创建；同名文件追加序号 `(1)`、`(2)`...

#### 2.2.2 新建日记

| 项目 | 要求 |
|------|------|
| 按钮文案 | `📅 新建日记` |
| 按钮颜色 | 蓝色（`hsl(207, 90%, 48%)`） |
| 目标文件夹 | 设置项 `diaryFolder`，默认 `日记` |
| 月文件名 | `yyyy年MM月.md`（如 `2026年05月.md`） |
| 日记标题 | `## yyyy年MM月dd日`（二级标题） |
| 打开方式 | 新标签页，编辑模式 |

**逻辑：**
- 检查 `日记/2026年05月.md` 是否存在
- 存在 → 读取内容，末尾追加 `\n\n## 2026年05月22日\n`，保存后打开
- 不存在 → 创建文件，写入 `## 2026年05月22日\n`，打开

### 2.3 模块二：收藏夹

**标题：** `收藏夹`（小号灰色大写）

以 2 列网格展示一组自定义快捷链接卡片，支持两种显示样式。

#### 2.3.1 显示样式

| 样式 | 设置值 | 布局 |
|------|--------|------|
| 横向（默认） | `horizontal` | emoji 在左，文字在右，水平排列 |
| 方形 | `square` | emoji 在上（24px），文字在下（11px），纵向居中 |

#### 2.3.2 卡片状态指示（左边框颜色）

| 状态 | 颜色 | 含义 |
|------|------|------|
| 蓝色边框 | `hsl(207, 90%, 54%)` | 目标为存在的 .md 文件 |
| 橙色边框 | `hsl(36, 100%, 50%)` | 目标为存在的文件夹 |
| 红色半透明 | `hsl(4, 90%, 58%)`，opacity 0.5 | 目标路径不存在 |

#### 2.3.3 点击打开逻辑

1. 尝试作为文件（含自动补 `.md` 后缀）→ 阅读模式打开
2. 尝试作为文件夹 → 查找文件夹内同名 .md 文件打开，否则用系统资源管理器打开
3. 都不存在 → Notice 提示 `路径不存在`

#### 2.3.4 数据结构

```typescript
interface QuickLink {
  id: string;        // 时间戳唯一标识
  emoji: string;     // 显示 emoji（默认 📄）
  name: string;      // 显示名称（默认 "新链接"）
  targetPath: string; // 目标路径（相对库根目录）
}
```

### 2.4 模块三：待处理

**标题：** `待处理`（小号灰色大写）

四张固定状态卡片，2 列网格布局，显示 `emoji + 名称 · 数量`。

| 卡片 | emoji | 左边框颜色 | 统计规则 | 点击目标 |
|------|-------|-----------|----------|----------|
| 待办 | 📋 | 蓝色 | 遍历全库 .md 文件，统计引用该页面的 wikilink（links + embeds）的文件数 | `todoPage`（默认 `待办`） |
| 未完成 | ⏳ | 橙色 | 同上 | `unfinishPage`（默认 `未完成`） |
| 剪藏 | 📑 | 绿色 | 读取目标 .md 文件，正则 `/^##\s+/gm` 统计二级标题数 | `clipPage`（默认 `剪藏`） |
| 缓存 | 📦 | 紫色 | 统计 `cacheFolder` 下所有 .md 文件数，排除与文件夹同名的 .md | `cacheFolder/文件夹名` |

**渲染策略：** 先显示缓存值（`countCache` Map），避免闪烁；异步计算完成后更新。

**刷新机制：**
- 监听 vault 的 `create`/`delete`/`rename`/`modify` 事件，500ms 防抖后自动刷新
- 设置保存（`saveSettings`）后立即刷新

### 2.5 模块四：语音朗读（新增）

**位置：** 侧边栏最底部，紧贴"待处理"模块下方，有上分隔线。

#### 2.5.1 控制面板

```
┌─────────────────────────────────────┐
│ 🔊 语音朗读                          │
│ 就绪 / 生成中… / 句子 3/42 / 已暂停   │
│ ████████████░░░░░░░░ （进度条）       │
│ [▶ 朗读]  |  [⏸ 暂停]  [⏹ 停止]      │
└─────────────────────────────────────┘
```

#### 2.5.2 按钮行为

| 按钮 | 操作状态 | 行为 |
|------|----------|------|
| **▶ 朗读** | 任何状态 | 发起新的 TTS 会话。有选中文本则从选中句开始读到文末，无选中则读全文 |
| **⏸ 暂停** | 播放中 | 暂停播放，按钮变为 `▶ 继续` |
| **▶ 继续** | 已暂停 | 恢复播放，按钮变回 `⏸ 暂停` |
| **⏹ 停止** | 播放/暂停 | 终止当前会话，清理音频 |

**视觉分组：** 朗读与暂停/停止间有竖线分隔。朗读按钮用主题色高亮，暂停/停止用默认色。

#### 2.5.3 双引擎策略

| 引擎 | 使用场景 | 特点 |
|------|----------|------|
| Edge-TTS | 全文朗读 | 微软神经网络语音（晓晓等），通过 WebSocket/TLS 直连微软服务，分批流式生成 |
| Web Speech API | 离线降级 / 选中朗读 | 浏览器内置，即时响应，无需网络 |

#### 2.5.4 分批流式播放

大文本按每批 5 句拆分，第一批 1-2 秒就绪后立即播放，后台同时生成后续批次。批次间无缝自动切换（前一批 Audio `ended` 事件触发下一批播放）。

#### 2.5.5 编辑器高亮

使用 CM6 `Decoration.mark()` 实现当前句子的背景色高亮，不影响编辑器选区（用户可同时编辑）。颜色通过设置中的 `ttsHighlightColor` 配置。

#### 2.5.6 命令面板入口

| 命令 ID | 名称 | 说明 |
|---------|------|------|
| `tts-read-full` | 朗读全文 | 使用 Edge-TTS 朗读当前笔记全文 |
| `tts-read-selection` | 朗读选中文本 | 使用 Web Speech 朗读选中内容 |
| `tts-stop` | 停止朗读 | 停止当前 TTS 会话 |

### 2.6 模块五：标签页管理

集成 Open In New Tab 插件的核心能力，统一管理标签页的打开与复用行为。

#### 2.6.1 复用已有标签页（reuseExistingTab）

受「标签页设置」中的开关控制（`reuseExistingTab`，默认开启）。

**启用时：**
- 跨三种路径生效：wiki 链接点击、文件浏览器点击、侧边栏快捷链接点击
- 文件已在主区域打开 → 跳转到该标签页（不创建重复标签页）
- 文件未打开 → 强制在新标签页中打开（不替换当前标签页）

**关闭时：**
- 透传 Obsidian 默认行为（wiki 链接在当前标签页打开，文件浏览器在当前标签页打开）

#### 2.6.2 wiki 链接拦截

通过重写 `Workspace.prototype.openLinkText` 实现。当用户点击编辑器中的 `[[file]]` 链接：

| 场景 | 行为 |
|------|------|
| 同文件锚点链接（`[[#标题]]` 或 `[[#^block]]`） | 透传原行为 |
| 目标文件已在任意标签页打开 | `setActiveLeaf` 跳转，然后以 `newLeaf=false` 调用原方法（保留标题跳转/滚动） |
| 目标文件未打开 | 以 `newLeaf=true` 调用原方法，强制新建标签页 |

路径匹配：使用 `endsWith` 宽松匹配，兼容子文件夹场景（如 `folder/note.md` 匹配 `[[note]]` 链接）。

#### 2.6.3 文件浏览器点击拦截

注册捕获阶段 `click` 事件监听器，匹配 `.nav-file-title` / `.nav-file-title-content` 元素，仅在纯左键（无修饰键）点击时生效：

| 场景 | 行为 |
|------|------|
| 目标路径已有匹配的标签页 | `stopPropagation` + `preventDefault`，`setActiveLeaf` 跳转 |
| 存在空白标签页（New Tab） | `setActiveLeaf` 到空标签页，不阻止默认行为（让 Obsidian 在该空标签页打开） |
| 其他 | `stopPropagation` + `preventDefault`，调用 `openLinkText(path, path, true)` 强制新标签页 |

#### 2.6.4 双击关闭标签页（doubleClickCloseTab）

受独立的开关控制（`doubleClickCloseTab`，默认开启）。通过 `registerDomEvent` 监听 `dblclick`，匹配 `.workspace-tab-header` 元素，找到对应 leaf 并 `detach()`。

#### 2.6.5 与侧边栏快捷链接的复用逻辑

侧边栏 `openFileInReadingMode()` 在 `reuseExistingTab` 开启时，检查主区域（`rootSplit`）已有标记为 markdown 的标签页，路径匹配则 `revealLeaf` + `setActiveLeaf`；否则 `getLeaf('tab')` 创建新标签页。

## 3. 设置需求

### 3.1 设置项列表

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `cacheFolder` | 文本 | `缓存` | 快速创建笔记的目标文件夹、缓存卡片统计目录 |
| `diaryFolder` | 文本 | `日记` | 日记月文件的存储文件夹 |
| `clipPage` | 文本 | `剪藏` | 剪藏卡片对应笔记路径（不含 .md） |
| `todoPage` | 文本 | `待办` | 待办卡片对应笔记路径（不含 .md） |
| `unfinishPage` | 文本 | `未完成` | 未完成卡片对应笔记路径（不含 .md） |
| `quickLinkStyle` | 下拉 | `horizontal` | 收藏夹卡片布局：`horizontal`（横向）/ `square`（方形） |
| `quickLinks` | QuickLink 数组 | `[]` | 常用链接列表 |
| `reuseExistingTab` | 开关 | `true` | 复用已有标签页 + 强制新标签页打开 |
| `doubleClickCloseTab` | 开关 | `true` | 双击标签页标题关闭该标签页 |
| `ttsEdgeVoice` | 下拉 | `zh-CN-XiaoxiaoNeural` | Edge-TTS 音色（15 种可选） |
| `ttsVoice` | 下拉（扫描） | `''`（系统默认） | Web Speech 本地音色 |
| `ttsSpeed` | 滑块 0.5-2.0 | `1.0` | 语速倍率 |
| `ttsHighlightColor` | 文本 | `#FFFACD` | 高亮背景色，带恢复默认按钮 |

### 3.2 设置面板布局（四个 Tab）

```
Tab 1 "侧边栏"     — 基础设置 + 常用链接管理
Tab 2 "标签页"     — 标签页设置 + 右键菜单
Tab 3 "样式隐藏"   — Markdown 格式隐藏 + HTML标签隐藏 + 空格可视化
Tab 4 "语音朗读"   — Edge-TTS 音色 / 本地音色 / 语速 / 高亮颜色
```

## 4. UI/UX

### 4.1 布局

```
┌─────────────────────────────┐
│  [📝 新建笔记] [📅 新建日记] │  ← 双按钮并排
├─────────────────────────────┤
│  收藏夹                      │  ← 标题
│  📝 项目管理    📋 读书笔记   │  ← 2列卡片（横向或方形）
│  📊 周报        🎯 目标      │
├─────────────────────────────┤
│  待处理                      │  ← 标题
│  📋 待办 · 12   ⏳ 未完成 · 5 │  ← 2列状态卡片
│  📑 剪藏 · 8    📦 缓存 · 23  │
├─────────────────────────────┤
│ 🔊 语音朗读                  │  ← 标题（上分隔线）
│  就绪                        │
│  ██████████░░░░ （进度条）    │
│  [▶ 朗读] | [⏸ 暂停] [⏹ 停止]│
└─────────────────────────────┘
```

### 4.2 样式要点

- 容器内边距 `12px 8px`，模块间距 `12px`
- 双按钮用 flex 行等分宽度，间距 `8px`
- 卡片 `min-width: 0` 确保网格两列等宽，文字溢出省略不改变卡片尺寸
- 卡片 hover 背景加深 + 上移 `1px` + 边框变色
- 网格 `grid-template-columns: repeat(2, 1fr)`，宽度 < 200px 时切换单列
- 禁用文本选择（`user-select: none`）
- 按钮点击期间显示"创建中…"并禁用
- TTS 按钮等宽（`flex: 1`），朗读按钮用主题色，控制按钮用默认色
- TTS 进度条 4px 高，圆角 `2px`

## 5. 非功能需求

| 项目 | 要求 |
|------|------|
| 性能 | 状态卡片数量异步计算，先显示缓存值避免闪烁 |
| 刷新 | Vault 事件驱动（500ms 防抖）+ 设置保存主动刷新 |
| 初始化 | `onLayoutReady` 后自动在左侧边栏创建视图 |
| 错误处理 | 操作失败弹出 Notice，不崩溃 |
| TTS 降级 | Edge-TTS 不可用时弹出提示并自动切到 Web Speech |
| 并发安全 | `aborted` 标志位防止重复点击产生重叠音频 |
| TTS 高亮 | CM6 Decoration，不影响编辑器选区，阅读模式可用 |
| 音色管理 | Edge-TTS 和 Web Speech 音色独立配置，互不干扰 |

## 6. 技术实现

### 6.1 文件结构

```
obsidian-sidebar-home/
├── main.ts              # 插件入口、生命周期、事件监听、CM6 扩展注册
├── settings.ts          # 类型定义和默认设置
├── setting-tab.ts       # 设置面板 UI（4 个 Tab）
├── sidebar-view.ts      # 侧边栏视图渲染和交互（4 个模块）
├── tab-utils.ts         # 标签页复用与强制新标签页（openLinkText 重写 + 文件浏览器点击拦截）
├── tts-player.ts        # TTS 播放调度核心（Edge-TTS + Web Speech + 分批流式）
├── edge-tts.ts          # Edge-TTS WebSocket/TLS 客户端（DRM + 帧编解码）
├── tts-highlight.ts     # CM6 Decoration 句子高亮
├── markdown-cleaner.ts  # Markdown → 纯文本
├── sentence-splitter.ts # 智能分句 + HTML 标签跳过搜索
├── format-hider.ts      # Markdown 格式符号隐藏
├── whitespace-visible.ts# 空格可视化
├── styles.css           # 全部样式
└── manifest.json        # 插件元信息
```

### 6.2 核心类

| 类名 | 父类 | 职责 |
|------|------|------|
| `SidebarHomePlugin` | `Plugin` | 入口：加载设置、注册视图/命令/事件/CM6扩展 |
| `SidebarHomeView` | `ItemView` | 视图：四个模块渲染、文件操作、统计计算 |
| `SidebarHomeSettingTab` | `PluginSettingTab` | 设置面板：4 个 Tab，语音列表扫描 |
| `TtsPlayer` | — | TTS 播放调度：引擎选择、分批流式、高亮同步 |

### 6.3 关键方法

| 方法 | 所属 | 功能 |
|------|------|------|
| `createDailyNote()` | SidebarHomeView | 生成时间戳文件名，创建空白笔记 |
| `createDiaryEntry()` | SidebarHomeView | 检查/创建月文件，末尾追加日期二级标题 |
| `countBacklinks()` | SidebarHomeView | 遍历全库统计 wikilink 引用数 |
| `countH2Headers()` | SidebarHomeView | 正则统计二级标题数 |
| `countCacheFiles()` | SidebarHomeView | 统计文件夹内 .md 文件数（排除同名） |
| `openTarget()` | SidebarHomeView | 智能路径解析：文件→文件夹→资源管理器 |
| `openFileInReadingMode()` | SidebarHomeView | 检查 `reuseExistingTab` → 复用/新建标签页 → 阅读模式 |
| `setupPathSuggestion()` | SidebarHomeSettingTab | 路径输入自动补全控件 |
| `patchOpenLinkText()` | tab-utils | 重写 `Workspace.prototype.openLinkText`，拦截 wiki 链接实现复用/新标签页 |
| `registerFileExplorerHandler()` | tab-utils | 捕获阶段 click 监听，拦截文件浏览器点击，复用/新标签页 |
| `playFullNote()` | TtsPlayer | 全文朗读（Edge-TTS 优先，分批流式，降级 Web Speech） |
| `playFromSelection()` | TtsPlayer | 从选中文本所在句子开始朗读 |
| `generateEdgeTts()` | edge-tts | TLS 直连 + 手写 WebSocket + DRM 令牌生成 |
| `buildBatchSsml()` | TtsPlayer | 构造 SSML XML，无效字符过滤 |
| `findSentenceOffsets()` | sentence-splitter | 跳过 HTML 标签定位句子在原文中的位置 |
| `highlightRange()` | tts-highlight | CM6 `StateEffect` 更新高亮范围 |

### 6.4 核心技术决策

| 决策 | 原因 |
|------|------|
| 不使用浏览器 WebSocket | 无法设自定义 HTTP 头（Origin/User-Agent），微软拒连 |
| 使用 Node.js `tls` 直连 | 完全控制请求头，模拟 Edge 浏览器 |
| 分批流式播放 | 大文本一次生成超时（>180s），分批第一批 1-2s 就绪 |
| CM6 Decoration 高亮 | 不影响编辑器选区，编辑和阅读模式均生效 |
| Web Speech 降级 | Edge-TTS 网络波动时用户仍可朗读 |
| 直接重写 `Workspace.prototype.openLinkText` | monkey-around 库在 Obsidian 类继承链中有潜在兼容问题；直接原型赋值 + 保存原引用更可靠 |
| `endsWith` 路径匹配 | wiki 链接 `[[file]]` 对应 `folder/file.md`，`===` 严格比较无法跨文件夹匹配 |
| `newLeaf=true`（非 `'tab'`） | 与 Obsidian 内部 `getLeaf(true)` 行为一致，兼容性更好 |
